POST-MORTEM

    HOW TO PLAY

    • Place: pick a component on the left, click a tile.
    • Link: drag from one node onto another. Start from the Users icon. Drag the same link again to remove it.
    • Move: drag a node onto an empty tile.
    • Delete: right-click a node, or select it and press Delete.
    • Zones: the three bands, top to bottom, are Availability Zones. An AZ outage kills every zonal node in that band. CDN, Load Balancer and Queue are managed services and survive.
    • Network levels (1-6): the map is one VPC. The two left columns are outside it (Internet Gateway, S3), yellow is public subnet, blue is private subnet. Click a node to set its Security Group and IAM. Your design carries over to the next level.
    • Packets: static read write async job.
    • Red X over a node: a request was dropped there. A label says why: OVERLOAD, DB DOWN, NO DB LINK, NO BACKEND, READ-ONLY. Click the node during a run for the full breakdown.
    • Run: traffic flows, chaos fires on schedule. Meet every requirement to pass. Spend 80% of budget or less for 3 stars.
